|  | Description |
|---|---|
| **Aims** | See the performance of the logit model and plug-in estimator under experimental data when the data are not generated from a logit model and the analysis is done under Neyman’s nonparametric setup. This includes looking specifically at standard deviation and bias. |
| **DGM: Model structure** | For $i\in[n]$, generate i.i.d. $\operatorname{Uniform}(0,1)$ random variables $U_i$ and $V_i$, and set $Y_i^C=\mathbf{1}(U_i>1/2)$ and $Y_i^T=\mathbf{1}(U_i+V_i>3/4)$. Then, with those values frozen, for each simulation randomly assign $75\%$ of $[n]$ to the treatment group and $25\%$ to the control group. The observed outcome for individual $i$ is then $Y_i^T$ if assigned to treatment and $Y_i^C$ if assigned to control. The data reported are then $V_i$, the assignments, and the observed outcomes. $n\in\{100,500,1000,5000\}$. |
| **Estimand** | Differential log odds of success under treatment vs control. |
| **Methods** | Assignment coefficient of the logit model fitted by maximum likelihood estimation (MLE); plug-in estimate from the same model. |
| **Performance measures** | Standard deviation and bias. The standard deviation is estimated using the sample standard deviation of the estimated quantities: $\widehat{\operatorname{SD}}(\widehat{\beta}_k)=\sqrt{\frac{1}{n_{\mathrm{sim}}-1}\sum_{i=1}^{n_{\mathrm{sim}}}\left(\widehat{\beta}_{k,i}-\overline{\widehat{\beta}}_k\right)^2}$. The sample bias is the difference between the average estimate and the true differential log odds: $\widehat{\operatorname{Bias}}(\widehat{\beta}_k)=\overline{\widehat{\beta}}_k-\Delta_n$. |
